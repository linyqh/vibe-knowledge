# 03 · 旁白与配音

## narration.json

```json
{
 "voice": {
  "engine": "breeze",
  "voice": "AI博主沉稳男声",
  "style": "你在录一节给职场人听的软件入门课。像一位亲切、干脆的年轻科普博主，语速从容，每句话讲清楚，句与句之间留出停顿，重点词稍微加重。"
 },
 "lexicon": {"PPT": "P P T", "GitHub": "Git Hub", "NLP": "N L P"},
 "beats": [{"id": "B01", "narration": "[[hi]]上一节，我们……[[now]]这一节，讲……"}]
}
```

- `voice.voice` 写 BreezeCast 里已保存的音色名或 id；`style` 作为 BreezeCast 的 `instruct`（语气 / 语速说明，逐句生效），必须和旁白同一种语言。可选 `"params": {"seed": 7}` 透传 BreezeCast 采样参数，英文版加 `"lang": "en"`。
- **一节**：18–28 拍，1200–2200 字（1.15 倍速后 4–7 分钟）。导学类 9–10 拍、约 750 字 ≈ 2.5 分钟。
- **一拍**：40–130 字，2–4 个 `[[cue]]`（小写英文/数字/下划线，放在分句开头）。画面元素用 `"B03.cue"` 或 `"B03@某个词"` 对齐到读到那个字的时刻。
- 口语、短句、第二人称。开头接上一节，结尾预告下一节 + 感谢原作者 + 「我们下节见」。
- 至少一个「暂停想一想」：一拍提问，下一拍 `[[answer]]` 揭晓。
- 不编造：数字、功能、界面文字、步骤以原文为准；原文没写的不补。引用逐字。

## BreezeCast 配音要点

- BreezeCast 是本机 app（BreezeTTS 2，REST 接口、无密钥）；音色在 BreezeCast 里：`scripts/voice_audition.py` 设计并 `--save`，或在 app 里克隆自己（已获授权）的声音。克隆要干净的单人录音 3–20 秒，逐字稿必须一字不差。
- 语言支持中文、英文，可混写。数字、日期、单位、缩写按口语写出来（`2024年`→`二零二四年`，`3.5%`→`百分之三点五`，`GPU`→`G P U`），或写进 lexicon。
- 每拍控制在约 300 字以内。
- 中文方括号如 `[笑]`、`[叹气]` 是发声事件；旁白里除非有意，不要写 `[]` 或 `【】`（`[[cue]]` 标记合成前会被剥掉）。
- **要加讲课语气说明**（`style`）：不加时语速偏赶；写了 `style` 时 guidance 自动取 4（更慢、更贴说明），语速以试听实测为准，仍偏慢可用 `scenes.speed: 1.15` 变速（atempo，音调不变）。
- 没有逐词时间戳 → 每拍整段合成后调用一次 Murmur `/transcribe`，同时拿到逐字时间戳（对齐）和转写文字（`--qa` 回读）；不需要 prompt，也没有模型回退。Murmur 转写时看不到原文。
- 逐拍合成（`--jobs 1`），按文字缓存；改过的拍才会重合成。

## 读音坑与 lexicon

- **罗马数字缩写**：全由 I V X L C D M 组成的大写缩写容易被念成数字（CLI→一百五十一、MD→一千五百、CC→二百）。`tts_breeze.py` 已自动拆成单个字母（ROMANISH 规则）；小写 cli/md 也可能念歪，写进 lexicon。
- 版本号写成「0 点 155 点 1」。
- 英文专名念歪的（GitHub、GEO、NLP、自造词）加进 lexicon 拆字母或加空格。
- 回读 QA 的 `odd_numbers`：回读里出现原文没有的 ≥100 的数字会 ⚠ 报出来。

## 回读质检（每节必看 voice.log）

- 每拍一行：时长、字数、字/秒、对齐率、合成耗时、回读相似度、差异。回读用 Murmur 转写（Qwen3-ASR），不是第二个 TTS 引擎。
- 回读 < 95% 或有 ⚠：删 `build/audio/<拍>.*` 再跑 voice，只重合成这几拍；两次都低就改措辞（换同义词、拆长句）再合成。
- 差异全是同音字 / 专名（例：它/他）时，可能只是转写差异：自己听 `build/audio/B07.wav`，或在 Murmur 里重新转写这一拍；念对了就不用重来。Murmur 转写时不看原文，但专名、人名仍务必自己再听一遍（例：苍何 → 回读「仓颉」可疑，复听是「苍和」= cāng hé，正确）。
- 偶尔会多念、重复或多加一个否定词（「不」），意思反了必须重来。

## 英文版

- narration：`voice.lang = "en"`，`voice` 用 BreezeCast 里的英文音色，`style` 写英文，Murmur 转写语言自动用英文，按词分段。
- scenes：`"lang": "en"`（界面文字表切英文、字幕按句断、52 字符宽）、`"inlineCredits": false`、`"videoOnly": true`（只出片）、`shotCredit` 写英文出处。
- 英文偶发多念/重复一句：回读 < 95% 就重合成。
